# Recurrent Neural Network for IMDB Text Sentiment Classification
## Overview

This project leverages a Recurrent Neural Network (RNN) for sentiment analysis on IMDB movie reviews, aiming to classify text as positive or negative based on its sentiment.


## Key Features

* Implementation of Artificial Neural Networks.

* Custom preprocessing pipeline for dataset preparation.

* Visualization of results and performance metrics.
## Technology Used

* Programming Languages: Python

* Libraries: TensorFlow, Keras, NumPy, Pandas, Matplotlib, Seaborn

* Tools: Jupyter Notebook

* Database/File Format: CSV


## Installation

1. Clone the repository:
git clone https://github.com/your-username/animal-clustering.git

2. Navigate to the project directory:
cd Day 60 Project.ipynb
## Run

1. Launch Jupyter Notebook:

   jupyter notebook

2. Open the notebook file Day 60 Project.ipynb and execute the cells sequentially.
## Conclusion

This project demonstrates the application of Artificial Neural Networks for solving text sentiment classification on IMDB movie reviews. Future work includes improving the model's accuracy, adding new features, and optimizing the pipeline for deployment.
